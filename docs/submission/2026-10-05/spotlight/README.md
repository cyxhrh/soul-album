## 发布步骤

1. 登录魔搭，打开 [开发者实践 / Spotlight](https://modelscope.cn/spotlight)，点击“创建内容”。官方入口链接指向 [创建页](https://modelscope.cn/learn/create)。如出现内容类型选择，选择适合图文介绍的“文章”。
2. 填入上面的标题、摘要，粘贴正文；按照实际编辑器的排版功能处理标题和链接，在两处图片位置上传对应原图。未核实一键导入 Markdown 功能。
3. 在文内视频位置插入魔搭原生视频组件，上传用户选定的 MP4。**2026-10-05 已在实际编辑器核实：支持本地 mp4 / mov / webm，单文件最大 2 GB。** 首次上传约 35 MB 的原片已被组件接受，最后可见进度为 67.94%，尚未验证上传完成或原生播放器；未完成组件已从正文移除。GitHub 视频链接保留为备用下载，不作为原生播放器是否成功的证明。
4. 若提供草稿或预览功能，先检查图片、视频链接、在线体验入口与能力说明，再发布。
5. 打开发布后的公开文章，复制平台实际生成的公开实践内容地址，按比赛表单的校验要求填写“实践内容”。发布前该项留空；不要填 MP4 下载地址、GitHub 仓库或创空间应用地址。

官方 [ms-cookbook 中文说明](https://github.com/modelscope/ms-cookbook/blob/main/README.zh-CN.md#参与共建)也给出“开发者实践 → 创建内容”的路径。当前已核对的 `modelscope-hub` 0.4.5 官方 CLI / OpenAPI 未发现文章创建或发布功能，本包不提供猜测的发帖命令。
