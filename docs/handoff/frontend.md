# 产品前端接手说明

默认入口已经是心灵画册产品本身：**对话、画册、生活数据**三页共用同一会话。当前交付是本地可运行的前端规则 Demo，问题由规则生成，图表使用固定合成数值和模拟授权。没有真实 AI、设备权限、账号、推送、跨设备同步或长期保存。启动与点击路径见仓库 [README](../../README.md)，[安全截图](evidence/README.md)展示界面状态，并非真实模型调用证据。

## 页面与状态

| 位置 | 职责 | 设计边界 |
| --- | --- | --- |
| `src/App.tsx` | 默认加载产品会话；保留独立合成剧情与节奏的查询参数入口。 | 作品介绍页不再是首页；旧演示与私人会话不能混入同一画册。 |
| `src/features/free/FreeTrial.tsx` | 三页外壳、单一聊天输入框、画册管理、邀请节奏、清空与打印提醒。 | `JournalState`、邀请、草稿和模拟授权只在当前 React 会话内；切页保留，刷新或清除即重置。浏览历史不能结算邀请；演示日必须显式推进。 |
| `src/domain/chatIntent.ts` | 仅供前端 Demo 使用的少量完整短语规则。 | 默认不猜深层意图；控制话语显示在聊天但不进画册。真实语言理解和可纠正判定属于后端阶段。 |
| `src/features/album/AlbumPage.tsx` | 单日页的原话、来源、修订状态及打印主体。 | 只为有效记录日生成；`mode="private"` 明确区分合成剧情，打印仅输出当前页。 |
| `src/features/data/DataInsights.tsx`、`src/data/behaviorSamples.ts` | 三种行为来源的逐项模拟授权、七日图表及数值表。 | 默认关闭；每项独立开启和撤回。数值为固定合成样例，不读取真实设备、不进入画册、不推断用户状态。 |
| `src/domain/journal.ts`、`selectors.ts`、`invitations.ts` | 唯一记录状态、日页派生和邀请调度。 | 修改／删除后的引用级联，以及“仅实际展示的整轮未回应才计入降频”属于行为契约。 |
| `src/features/story/GuidedStory.tsx`、`src/features/rhythm/RhythmDemo.tsx` | 保留的旧合成演示，分别可通过 `?demo=story` 与 `?demo=rhythm` 查看。 | 不进入默认导航，不冒充用户历史。 |

用户自由输入不会写入 `localStorage`、`sessionStorage` 或 IndexedDB，也没有业务网络请求。浏览器测试使用哨兵检查网络、控制台和持久存储。用户主动打印或另存 PDF 后，文件已经离开页面内存边界，因此打印前有提醒。

## 视觉与交互

`src/styles/tokens.css` 保留纸底 `--paper: #f7f4ed`、日页 `--leaf: #fffdf8`、墨绿 `--ink: #24332e`、青绿 `--green: #5c8c7b`；`src/styles/product.css` 负责产品外壳、聊天气泡、固定输入区、桌面侧栏和手机底栏；`src/features/data/data.css` 负责数据图表。`src/styles/app.css` 仍包含旧剧情、画册和打印相关样式。`src/styles/print.css` 只保留 A4 当前日页事实，隐藏操作区和三页导航。

聊天以阅读和发送为中心，不出现“回答问题／主动分享／跳过这一题／今天不想答”模式按钮。少量完整的自然话语由透明的本地规则处理；有待答问题时，普通消息暂作为本轮回应保存，明确的“随手记：…”前缀可在当轮另记一句但不消耗问题。可见来源统一为“本次页面对话”，不自称模型已理解用户意图。明确的换题、拒答话语只保留在当前聊天，不进画册或打印。后端模型的未来职责是理解更开放的表达，并让用户能纠正判断。画册可从有效原话回看与修订，数据页把“来源、范围、单位、模拟性质”放在图表旁。已记录的气泡与日页都从同一份记录派生，不另存一份私人原话。保留键盘焦点、文本标签、图表数值表与减少动效支持；375px 手机和 1440px 桌面是主要检查宽度。

## 回归门槛

运行 `npm run test`、`npm run test:e2e`、`npm run build`、`npm run lint`。浏览器重点复核默认对话、单一输入框、明确换题／拒答话语不入画册、含相似词的普通原话不被误丢、跨页保留草稿、消息形成日页、历史回看不推进邀请、编辑／删除后的引用级联、三种模拟授权分别撤回、清除与刷新、打印提醒的焦点、窄屏输入区和长页滚动。截图和 A4 打印页是视觉 QA 的一部分。

下一阶段若接入真实模型、设备数据和账号，需单独设计每个来源的授权、上传说明、撤权清理、数据存储与跨设备同步契约；当前模拟开关不能被解释为这些能力已实现。
