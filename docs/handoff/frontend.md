# 产品前端接手说明

## 当前状态：2026-10-01

当前产品是**渐知**。本轮以 5176 对应工作树完成微信式聊天、分时开场、每日画册正反面、完整问答收录、Markdown 编辑下载和浏览器持久恢复。当前说明以[本轮交付](jianzhi-competition-upgrade-2026-10-01.md)为准，下面保留的 2026-09-29/30 描述是历史基线，其“刷新清空”“不进浏览器缓存”“模型回答不进入画册”已被本轮替换。

新增模块：`dailyRecord.ts` 管理 Markdown；`dailyArchive.ts` 汇总有效完整对话并撤下过时肖像；`DailyAlbum.tsx` 管理正反面、显式整理和修订；`sessionPersistence.ts` 与 `freeSessionCache.ts` 验证及保存浏览器会话。`POST /api/ai/daily-album` 使用现有本机 Qwen 服务及限额。普通聊天的 800 字片段范围不变，跨日记忆未接入。

当前回归重点：刷新恢复、缓存失败与备份、编辑中切日期、迟到生成结果、完整长文本、删除后派生撤回、明确确认清除、正反面不调用模型。模拟设备授权仍在刷新后重置。验证范围及截图见本轮交付；旧版测试数不能代表当前版本。

## 历史基线：2026-09-29

默认入口是心灵画册产品本身：**对话、画册、生活数据**三页共用同一页面会话。当前交付是本地可运行的内存 Demo：对话记录与日页使用 `backend/local/` 领域服务，邀请节奏仍由前端规则演示，图表使用固定合成数值和模拟授权。桌面/手机视觉、画册详情、生活数据日报及浏览器本地语音输入参考队友 [LCX206/soul-album](https://github.com/LCX206/soul-album/tree/6fe3831d85287a685a6310187c4c410da902833a)。本机服务已配置时，默认聊天直接使用当前模型；无服务时标出规则回退，不再让用户选择模式或逐句授权。先前逐句版的[合成资料记录](../evidence/2026-09-29-private-chat-synthetic-trial.md)只证明当时的路径，不证明新版长期对话质量。没有真实设备权限、账号、推送、跨设备同步、用户记录加密存储或长期保存。启动与点击路径见仓库 [README](../../README.md)。

用户自由输入不会写入 `localStorage`、`sessionStorage` 或 IndexedDB。本机已配置模型时，用户按发送即经 `/api/ai/private-chat` 发出本句和限定的近期已发送会话上下文；不会补传离线旧句、任意旧日画册、观察纠正或设备模拟数据。模型未配置时规则回退；已发请求失败则保留原话但不伪造模型回复、也不自动重试。编辑/删除来源会撤下依赖它的回复。模型回复只是聊天气泡，不进入画册。录音与语音转写只在浏览器内运行，转写结果是未发送草稿。用户主动打印或另存 PDF 后，文件已离开页面内存边界，因此打印前有提醒。演示第 N 天映射到虚拟日期，不能当作真实生活日期。详见[统一模型对话契约](../contracts/auto-chat-v2.md)。

## 视觉与交互

2026-09-29 的聊天优化以 `codex/teammate-frontend-integration` 整合工作树为基准（本机预览 `http://127.0.0.1:5176/`）。`src/styles/messenger.css` 在队友样式之后加载，单独定义浅灰聊天底、白绿气泡、联系人“小册”与头像、顶部模型状态和省略号设置菜单；`ChatIdentity.tsx` 提供本地 SVG。画册翻页、页面工具、朱红纸墨主题、日报式数据页和语音处理沿用整合版。没有从旧主目录覆盖 `FreeTrial.tsx` 或后端代码。

输入框随文字自动增高，最多 144px，切页和语音转写完成后重新测量；点击发送后回到输入框。麦克风、录音波形、取消与重试仍走原来的状态流程。邀请设置移到右上角，支持点击外部收起、Esc 收起并回焦，窄屏菜单内部滚动。原有的清除、详情和模型发送范围说明继续可用；按用户要求，聊天气泡不再展示“查看当时发送的内容”及请求 JSON。模型名称和可用状态来自原有 `/api/ai/model-status`；聊天请求和上下文限制仍由原有 `/api/ai/private-chat` 路径处理。

本轮验收：238 项单元测试、80 项浏览器测试、`build:all` 和 lint 通过。新增 `tests/messenger.spec.ts` 覆盖菜单回焦、多行草稿、发送后继续输入和手机底栏分离；既有测试覆盖语音状态、三轮模型对话、来源撤回、双页画册与打印。模型浏览器测试使用受控响应，不调用正在运行的付费服务，也不代表真实千问质量验收；手机软键盘尚未做真机验证。

`src/styles/tokens.css` 采用队友版暖白纸底、墨色文字与朱红强调色，并保留旧变量别名供保留的剧情演示使用；`src/styles/product.css` 负责产品外壳、气泡、固定输入区、桌面侧栏、桌面双页画册及手机单页；`src/features/data/data.css` 负责日报与图表。画册下方“页面工具”默认收起，整理、对照与已回答问题仍可展开操作。`src/styles/app.css` 包含画册详情、旧剧情等样式；`src/styles/print.css` 只保留 A4 当前日页事实，隐藏扉页、翻页控件、工具区和三页导航。语音模型与 WASM 静态文件随站点提供，来源及首次加载体量见 README。

聊天以阅读和发送为中心，不出现“回答问题／主动分享／跳过这一题／今天不想答”模式按钮，也不出现模型／规则切换和逐句授权弹窗。界面显示本机服务报告的当前模型名称，说明聊天发送范围；`ready` 只代表已配置，不能宣称云端已连通。离线回退中少量完整的自然话语由透明规则处理；有待答问题时，普通消息暂作为本轮回应保存。模型可理解更开放的表达，但用户仍可纠正判断。画册可从有效原话回看与修订，数据页把“来源、范围、单位、模拟性质”放在图表旁。已记录的气泡与日页都从同一份记录派生，不另存一份私人原话。保留键盘焦点、文本标签、图表数值表与减少动效支持；320px、375px 手机和 1440px 桌面是主要检查宽度。

## 回归门槛

运行 `npm run test`、`npm run test:e2e`、`npm run build`、`npm run lint`。浏览器重点复核默认对话、单一输入框、明确换题／拒答话语不入画册、含相似词的普通原话不被误丢、跨页保留草稿、消息形成日页、历史回看不推进邀请、编辑／删除后的引用级联、三种模拟授权分别撤回、清除与刷新、打印提醒的焦点、窄屏输入区和长页滚动。截图和 A4 打印页是视觉 QA 的一部分。

当前本机千问端点只接受主动发送且有界的会话文字，仍无正式用户认证或生产级隐私存储。真实设备数据和账号仍需分别设计来源授权、上传说明、撤权清理、数据存储与跨设备同步契约；当前模拟开关不能被解释为这些能力已实现。
# 分时开场更新（2026-09-30）

- 默认首页按用户本地时间展示早上／中午／下午／晚上／深夜五套固定开场；每个内存会话只选一次。切页、跨时段不重复欢迎，清除或刷新重新开始。未回答前暂停邀请会收起开场。

- 欢迎语不创建日记条目；发送范围说明保留在详情，首页展示聊天气泡。
