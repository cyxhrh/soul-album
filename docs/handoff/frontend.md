# 产品前端接手说明

默认入口是心灵画册产品本身：**对话、画册、生活数据**三页共用同一页面会话。当前交付是本地可运行的内存 Demo：对话记录与日页使用 `backend/local/` 领域服务，邀请节奏仍由前端规则演示，图表使用固定合成数值和模拟授权。桌面/手机视觉、画册详情、生活数据日报及浏览器本地语音输入参考队友 [LCX206/soul-album](https://github.com/LCX206/soul-album/tree/6fe3831d85287a685a6310187c4c410da902833a)；本项目还可在本机显式切换到逐轮授权的千问聊天。两轮真实浏览器回复和一次纠正的独立接口复测见[合成资料记录](../evidence/2026-09-29-private-chat-synthetic-trial.md)，不证明长期对话质量。没有真实设备权限、账号、推送、跨设备同步、用户记录加密存储或长期保存。启动与点击路径见仓库 [README](../../README.md)。

## 页面与状态

| 位置 | 职责 | 设计边界 |
| --- | --- | --- |
| `src/App.tsx` | 默认加载产品会话；保留独立合成剧情与节奏的查询参数入口。 | 作品介绍页不再是首页；旧演示与私人会话不能混入同一画册。 |
| `src/features/free/FreeTrial.tsx` | 三页外壳、单一聊天输入框、浏览器本地语音草稿、画册双页与翻页、邀请节奏、清空与打印提醒。 | 消息与日页调用单次页面内存服务；邀请、草稿和模拟授权只在当前 React 会话内。切页保留，刷新或清除即重置。画册仅在已有记录日之间翻页，不推进演示日；演示日必须显式推进。 |
| `src/domain/browserLocalSession.ts`、`backend/local/` | 把演示日期映射成日期，在内存事务中处理消息、问句、日页、标题和编辑删除，并给画册提供只读投影。 | 原话只以领域记录为准；气泡和画册读取同一份有效记录。虚拟日不应被解释为用户实际经历日期。 |
| `src/domain/chatIntent.ts` | 仅供前端 Demo 使用的少量完整短语规则。 | 默认不猜深层意图；控制话语显示在聊天但不进画册。真实语言理解和可纠正判定属于后端阶段。 |
| `src/features/album/AlbumPage.tsx` | 单日页的原话、来源、修订状态及打印主体。 | 只为有效记录日生成；`mode="private"` 明确区分合成剧情，打印仅输出当前页。 |
| `src/features/data/DataInsights.tsx`、`src/data/behaviorSamples.ts` | 按日期阅读的日报、三种行为来源的逐项模拟授权、七日图表及数值表。 | 默认关闭；每项独立开启和撤回。数值为固定合成样例，不读取真实设备、不进入画册、不推断用户状态。 |
| `src/domain/journal.ts`、`selectors.ts`、`invitations.ts` | 前两者保留旧画册投影类型与选择器，后者处理模拟邀请调度。 | `journalReducer` 已不管理默认产品的私人原话；演示邀请与领域服务邀请尚未接线，不能宣称领域层已实际驱动降频。 |
| `src/features/story/GuidedStory.tsx`、`src/features/rhythm/RhythmDemo.tsx` | 保留的旧合成演示，分别可通过 `?demo=story` 与 `?demo=rhythm` 查看。 | 不进入默认导航，不冒充用户历史。 |
| `src/features/ai/AiLab.tsx` | 独立的阿禾合成资料模型实验，`?demo=ai` 可打开，剧情末尾也有入口。 | 请求只含固定场景标识；结果是待确认提议，不能进入私人记录。无 Key 或失败时显示规则示例，不标为模型成功。 |

用户自由输入不会写入 `localStorage`、`sessionStorage` 或 IndexedDB。默认本地规则模式不向模型发送原话；本机千问模式每轮先在本页保存，再让用户预览实际 JSON 并单次同意，才通过 `/api/ai/private-chat` 发送所选片段。取消或失败不产生伪造回复；编辑/删除来源会撤下依赖它的回复。模型回复只是聊天气泡，不进入画册。录音与语音转写只在浏览器内运行，转写结果是未发送草稿。用户主动打印或另存 PDF 后，文件已离开页面内存边界，因此打印前有提醒。演示第 N 天映射到虚拟日期，不能当作真实生活日期。

## 视觉与交互

`src/styles/tokens.css` 采用队友版暖白纸底、墨色文字与朱红强调色，并保留旧变量别名供保留的剧情演示使用；`src/styles/product.css` 负责产品外壳、气泡、固定输入区、桌面侧栏、桌面双页画册及手机单页；`src/features/data/data.css` 负责日报与图表。画册下方“页面工具”默认收起，整理、对照与已回答问题仍可展开操作。`src/styles/app.css` 包含画册详情、旧剧情等样式；`src/styles/print.css` 只保留 A4 当前日页事实，隐藏扉页、翻页控件、工具区和三页导航。语音模型与 WASM 静态文件随站点提供，来源及首次加载体量见 README。

聊天以阅读和发送为中心，不出现“回答问题／主动分享／跳过这一题／今天不想答”模式按钮。少量完整的自然话语由透明的本地规则处理；有待答问题时，普通消息暂作为本轮回应保存，明确的“随手记：…”前缀可在当轮另记一句但不消耗问题。可见来源统一为“本次页面对话”，不自称模型已理解用户意图。明确的换题、拒答话语只保留在当前聊天，不进画册或打印。后端模型的未来职责是理解更开放的表达，并让用户能纠正判断。画册可从有效原话回看与修订，数据页把“来源、范围、单位、模拟性质”放在图表旁。已记录的气泡与日页都从同一份记录派生，不另存一份私人原话。保留键盘焦点、文本标签、图表数值表与减少动效支持；375px 手机和 1440px 桌面是主要检查宽度。

## 回归门槛

运行 `npm run test`、`npm run test:e2e`、`npm run build`、`npm run lint`。浏览器重点复核默认对话、单一输入框、明确换题／拒答话语不入画册、含相似词的普通原话不被误丢、跨页保留草稿、消息形成日页、历史回看不推进邀请、编辑／删除后的引用级联、三种模拟授权分别撤回、清除与刷新、打印提醒的焦点、窄屏输入区和长页滚动。截图和 A4 打印页是视觉 QA 的一部分。

当前本机千问端点是试验路径，只接受逐轮批准的小段文字，仍无正式用户认证或生产级隐私存储。真实设备数据和账号仍需分别设计来源授权、上传说明、撤权清理、数据存储与跨设备同步契约；当前模拟开关不能被解释为这些能力已实现。
