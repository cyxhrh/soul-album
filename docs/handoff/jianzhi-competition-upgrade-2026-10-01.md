# 渐知：比赛前端优化交付

日期：2026-10-01。基准为 `codex/teammate-frontend-integration` 工作树，预览 http://127.0.0.1:5176/ 。已保留队友和此前全部未提交改动；本轮没有提交或推送。

## 优化方案与已实现体验

1. **整体质感**：渐知品牌、植物绿与纸色、统一导航与排版。保留队友的三页结构和后端接口，手机输入区与底部导航不重叠。
2. **像聊天一样开始**：联系人小册持续标为 AI 记录伙伴；白绿气泡、无气泡内时间、按早上/中午/下午/晚上/深夜选择开场。同一已保存会话刷新后不重复变换欢迎。型号详情收入设置，离线状态仍明显。
3. **每日画册两面**：正面为可编辑标题与简洁日记；背面保留完整用户文本、有效模型回答及系统问候，以及明确事实、自述感受、暂定观察与不确定之处。暂定观察可展开原话依据。
4. **可修改、可带走**：正面独立编辑；背面编辑 Markdown 先预览再保存，修订消息明确标记。下载真实 UTF-8 `.md`；任意 Markdown 符号、中文、换行与长文尾部原样保留，HTML 不执行。未保存的编辑草稿也可下载。
5. **真实留存**：聊天、消息草稿、邀请状态和每日档案保存到此浏览器，刷新可恢复；模拟设备开关刷新重置。清除须明确确认，缓存损坏/满额/跨页面冲突不宣称保存成功；损坏缓存保持原样，可下载备份。
6. **比赛演示**：没有真实记录时展示隔离的合成样例，可翻面、修改与重置；聊天新增“看看今天这一页”。已有原话管理、摘录对照与历史依据保留在页面工具内。

## 整理、修订与删除规则

- 翻面、查阅、编辑与下载不调用模型。只有“整理今天”把该日完整有效档案交给当前模型；首次成功采用，已有日记则先展示候选日记与新肖像，用户决定是否替换。
- 本日最多 30,000 Unicode 字符、200 条消息；超限拒绝并保留全文，不截断。普通聊天仍沿用本句前 800 字及限量近期已发送上下文，不能将它当作全文整理或跨日检索。
- 整理失败、超时、格式不完整或引用非用户消息时保留原文，不伪造成功；来源更新或组件卸载后迟到结果不写入当前记录。
- 修改聊天原话时撤下依赖它的模型回答、AI 日记与肖像；手写日记保留，其他未变消息的档案修订保留。删除原话前说明影响，并撤下可能含删除内容的日记与肖像，不暗中保存删除内容的历史副本。
- 修改 Markdown 的对话文本不改写当时聊天，旧日记与肖像在保存预览中撤下；再次整理与导出使用当前修订版。元数据、顺序与角色不可伪造。
- 画册编辑期间阻止切日期，浏览器离开提醒及草稿下载辅助保留未保存内容。保存中的来源若变化，草稿保留但禁止写回旧版本。

## 本轮能力边界

浏览器缓存没有加密或跨设备同步，下载后编辑的电脑文件不会自动同步回页面；清除浏览器数据会失去未导出的记录。缓存 JSON 备份供保留与排查，尚无用户导入恢复入口。Markdown 编辑针对本应用导出的结构，未提供任意 Markdown 文件导入。

当前保存有效修订与版本号，采用前可比较；独立历史回退暂缓。画册供本日整理实际读取，普通聊天尚未按需读取跨日画册，不宣称已完成长期记忆。当前仍为比赛本机演示，真实设备来源、账号及公开部署不在本轮。
