# 统一模型对话契约（本机 Demo）

本文件是默认产品对话的当前契约，取代[逐轮预览试验](private-chat-pilot.md)。产品只有一个聊天输入框，不要求用户选“千问聊天／本地规则”，也不在每句话后弹出授权窗口。本机服务配置了模型时，用户按“发送”或 Enter 即授权把**本次限定内容**送往该模型；不发送草稿、录音、整本画册或设备模拟数据。用户可在页面详情看到当前模型及发送范围。当前提供方只有百炼／千问，模型 ID 从本机服务读取；将来可更换提供方，不在这一版加入模型选择器。

## 发送与记录

1. 页面读取 `GET /api/ai/model-status`，只获取 `ready`／`unavailable` 与 `{provider,id}`。`ready` 表示本机已配置且本进程尚有调用次数，不保证云端网络、额度或模型健康；不返回 Key，也不触发模型调用。若无本机服务、接口返回旧版 404 或状态无效，界面明确进入规则回退。
2. 只有用户主动发送消息才触发 `POST /api/ai/private-chat`。语音转写仅填入未发送草稿；打开页面、切页、看画册、推进演示日、刷新模型状态均不自动发送消息。用户原话先保存在当前页面内存，进入画册；模型回应只是可撤下的聊天气泡，不写成用户事实。
3. 一次请求只能包含本句原话连续片段（1–800 字）、本页会话**同一演示日内此前实际发给模型**且仍有效的最多两条近期用户原话，以及上一条仍有效的模型回复和可选追问。离线规则期保存的旧句在服务恢复后不会补发；任意旧日画册内容、观察纠正、未发送草稿、手表步数、消费记录和应用时长均不自动进入请求。浏览器发送前及响应后复核来源修订；编辑、删除或清除后，依赖旧来源的模型回复不得保留或回填。
4. 本机模型未配置或本机状态不可达时，页面明确显示规则回退。已经向模型发起的一轮若超时、限流、断网、输出校验失败或配额耗尽，原话仍在本页，但不伪造模型回复、不静默改称规则生成、不自动重试。一次发送只产生一条本地消息和至多一次上游尝试；连续点击、按 Enter 或慢响应均不可重复提交。

本机代理仍接受同源 `application/json` 的 `POST /api/ai/private-chat`：

```json
{
  "turn": {"kind":"entry","id":"entry-2","revision":1,"day":2,"quote":"今天下班时看到晚霞。"},
  "context": [{"kind":"entry","id":"entry-1","revision":1,"day":2,"quote":"早些时候说想留一点散步时间。"}],
  "precedingAssistant": {"reply":"下班路上的晚霞听起来让你停了一下。","nextQuestion":"你想记住当时的什么细节？"}
}
```

代理限制请求体、来源数和字数、回环 Host／Origin、调用次数、速率与超时，并要求模型回应符合固定格式及逐字引用约束。服务器没有浏览器的本地记录库，无法自行证明来源 ID 或版本真实；浏览器必须完成上述来源核验。服务端只提供安全错误码，不返回 Key、Prompt 或上游错误正文；接口响应 `Cache-Control: no-store`。模型回答及引用仍可能理解错误，用户可用下一句自然纠正，但不会自动改写过去的日记。

## 本机运行与边界

密钥由 Windows 用户本机 DPAPI 副本提供给本机服务，绝不写入前端、仓库、聊天或 `VITE_` 变量。启动器的 `-Model` 选择**服务配置**，页面只显示服务返回的当前模型；`-MaxCalls` 限制该进程的上游尝试次数，失败也计数，重启会重置，因此不是费用上限。公开 GitHub Pages 只承载静态规则体验，不连接用户本机模型服务。本 Demo 没有账户鉴权、生产级加密存储或跨设备同步。

百炼[官方隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)指出调用数据可能由提供方存储。页面清除只影响当前页面内存，无法撤回已经送达提供方的文本。真实设备资料未来接入时仍须逐来源设计授权、撤权与同步边界；本次对话自动发送不等于许可读取手表或手机内容。

验收用合成资料和假提供方覆盖：状态 GET 不调用模型；连续对话无逐句弹窗；发送体不含离线旧句、未发送草稿和设备资料；双击、慢响应、编辑删除、清除、服务失败和离线恢复都保持来源与请求边界。真实麦克风、真实百炼质量和生产部署需另外验证。
