# 本机主对话：单次私人提问试验契约

**状态：代码已接线并通过本轮合成资料与假 provider 回归；尚无真实私人内容的百炼调用佐证。** 这是比赛 Demo 的本机可选路径，不是 [API v1](api-v1.yaml) 中拟议的生产级 `/v1/analysis/proposals`。默认聊天先显示本地规则题；[阿禾合成接口](ai-experiment.md)继续只处理固定资料，与此端点隔离。

## 开启与确认

普通 `npm run dev` 和公开 GitHub Pages 使用规则问题。私人提问按钮仅在浏览器地址为 `localhost`／`127.0.0.1`、当前待答规则题关联一条有效原话时出现。服务端仅监听回环地址；即使配置密钥，也要用 `scripts/run-qwen-local.ps1 -EnablePrivateQuestions` 单独开启私人端点。页面每次弹出预览；只打开或取消预览不发请求，点击“同意并发送这一次”才发送。服务端无法仅凭 HTTP 请求证明用户真的看过预览，所以此本机实现不得直接公开部署。

用户可在预览中删减 `quote`，但它必须是关联记录**当前版本中连续、逐字一致**的一段，包含 6–800 个字符；不能凭空改写。弹窗显示实际发送到本机服务的完整 JSON：

```json
{"entry":{"id":"source-entry-id","revision":1,"quote":"今天下班后在路边看见晚霞。"}}
```

`POST /api/ai/private-question` 使用同源 `application/json`。服务端要求严格的单对象编码、回环 Host／Origin、最多 4096 字节请求体，且单片段不超过 1000 字；页面有更低的 800 字限制。浏览器只发送该 ID、修订号和选定片段到本机代理。**代理只验证修订号的格式**：它没有浏览器画册快照，不能判断这个版本是否仍然有效。浏览器在发送前、响应后检查当前版本，本地领域事务在采纳时再原子检查。百炼上游请求收到的是该 ID 和片段，**不是整本画册或修订号**。如果原话不超过限制且用户不删减，选定片段可能等于整条原话。服务器持有 API 密钥并设调用次数、每分钟请求数和超时上限；不自动重试。

## 返回与本地采纳

成功响应示意（例子不是调用证据）：

```json
{
  "status":"generated",
  "question":"看到晚霞时，你想到了什么？",
  "citations":[{"id":"source-entry-id","quote":"今天下班后在路边看见晚霞。"}],
  "model":{"provider":"qwen","id":"configured-model-id"},
  "generatedAt":"2026-09-29T00:00:00Z"
}
```

服务端必须核对问句长度、格式和显性高风险内容，以及引用 ID 和选定片段逐字相同；字面核对不能证明语义关联或提问质量。前端收到候选后，再核对会话空间、待答问题、原话 ID／修订号／片段都仍有效；领域服务在同一事务中把该待答规则题改成 `cloud_model`，并把**用户本次实际批准的片段**写入 `Question.approvedExcerpt`。当前题和已回答历史题均以折叠证据显示这个字段，用户能核对到底发了哪一段；它不能当作下次自动发送的授权。来源改写／删除会在同一事务清除失效题干与 `approvedExcerpt`，即使历史题已回答也不可继续回显。题目已作答／跳过、用户取消、页面重置或迟到响应都不能重新插入旧内容。发送前取消是零请求；发送后取消只放弃结果，本机服务会尝试中止尚未完成的上游调用，已发内容无法撤回且可能计费。成功界面标“千问提议”，用户可指出理解偏差并提供自己的背景；纠正会撤下这道待答题并影响下一问。模型失败时保留可作答的本地规则题。

用户在较晚演示日纠正一条引用旧日原话的模型问题时，纠正记录的 `journalDate` 来自本次 `correctedAt`，因此会显示在**实际纠正日**画册；其 `citations` 仍指向旧日来源的 ID／修订号，依据可逐条展开查看旧日原话。同一天的多条有效纠正按顺序出现在聊天、画册和打印页。当天没有新回答也能形成纠正日页；旧日来源改写或删除后，依赖它的观察从纠正日页撤下，该日若无其他有效内容便不再列出。这一纠正不改变旧日原话本身，也不会把两天误写成同一天发生。

错误只有安全码与提示，不回传上游正文、Prompt 或密钥；响应 `Cache-Control: no-store`。可见错误包括 `400 invalid_request`、`429 rate_limited`、`503 model_not_configured`／`model_unavailable`、`504 model_timeout`、`502 invalid_model_output`、`422 no_reliable_citation`。这个端点没有生产账号鉴权、加密持久化、跨设备同步或正式审计；不能把回环限制和 UI 弹窗称为完整数据安全方案。

百炼[官方隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)称客户数据不用于模型训练，同时明确会存储模型与应用调用产生的数据。因此“本次页面关闭即清空”只描述本应用内存状态，**不包括用户已同意发送的提供方副本**。验收用合成记录与假 provider；目前没有用真实私人内容调用上游的证明。
